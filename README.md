# Katalon-demo-cura

Automated UI test suite for the CURA Healthcare Service application, designed to demonstrate proficiency in modern test automation practices.

Tech Stack

- Test Framework: Playwright
- Language: TypeScript
- Design Pattern: Page Object Model (POM)
- Scope: UI automated tests

Key Features

- End-to-end testing of the appointment booking workflow.
- Cross-browser testing (Chromium, Firefox, WebKit).
- Parallel execution support to optimize CI/CD pipeline performance.
- Clean, maintainable test architecture using Page Object Models.

Prerequisites

- Node.js (Latest LTS version)
- Playwright installed (npm install -D @playwright/test)
